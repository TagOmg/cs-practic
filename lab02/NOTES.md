ИСПОЛЬЗОВАНЫЕ КОМАНДЫ
git - инструмент сохранения истории изменения файлов, а github сервис где можно хранить файлы
Отправлять и получать их оттуда
git status - получение информации о состоянии на данный момент.
git diff - информация об изменениях в катологе 
git diff --staged - информация об изменениях в катологе , после добавления изменения с помощью gti add
ВЕТКИ
Ветка - это отличная от основной линия изменений, если не стоит изменять основную
слияние соединят две ветки, их коммиты, изменения в одну.
