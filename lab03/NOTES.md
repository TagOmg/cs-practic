git diff - показывает разницу между коммитами
git log - показывавет историю коммитов
git show - показывает что именно изменилось в этом коммите 
log -S ничего не выдало
blame выдало код построчно и когда эти строчки появились и в каком коммите
git restore файл откатывается к последнему коммиту HEAD
git restore ==source Команда берет версию файла из указанного коммита и копирует её директорию
